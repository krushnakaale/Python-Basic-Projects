# Smart QR Generator | Project 08
Offline QR generator with a clean Kivy interface. Supports text, URLs, email, phone and Wi-Fi, dark custom colors, image sizes and error correction. Generate then preview and export PNG. Wi-Fi QR codes contain credentials; share only with intended recipients. No history is stored.

## Sample outputs

Each QR code is a 512 x 512 PNG generated by the project. Select a preview to open the full-size PNG.

## Windows (Python 3.11 or 3.12)
```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```
Activate the environment before running `scripts\build_windows.bat`. Output: `builds/windows/SmartQRGenerator.exe`. PNG exports: `~/SmartQRExports`.

## Android (Kali WSL2)
Copy the source into Linux home, excluding Windows virtual environments and build outputs. Install compatible Java (JDK 17 recommended), Python, compiler and Android build dependencies per https://buildozer.readthedocs.io/en/latest/installation.html . Create a Linux venv, install buildozer, setuptools and cython<3, then run `bash scripts/build_android.sh`. Output: `builds/android/`. Android PNG exports are app-private, not automatically visible in Gallery. Build compatibility depends on installed toolchain. Debug APK is not a store release.
